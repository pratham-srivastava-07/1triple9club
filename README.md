# 1triple9 Club

**Payment ka breakup kar do.** Generate downloadable UPI QR codes for a collection, split into payments of ₹1,999 or less. Everything runs in the browser.

## Run locally

```bash
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000).

QR generation happens locally. The tool does not verify payments or provide legal advice.
